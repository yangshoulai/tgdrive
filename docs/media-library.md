# 媒体库与收录管理

媒体库是普通文件的浏览视图。收录设置只决定是否展示，不改原文件、内容类型、ETag、修改时间与公开权限，不影响收藏、已有歌单或「最近」。私密空间、回收站与系统资源始终不进入媒体库。

## 分类

- 相册、影视、音乐沿用已有图片、视频、音频识别。没有拍摄时间、歌曲标签或时长时仍能自动收录，不用这些缺失信息断定文件没有价值。
- 书籍自动收录 EPUB、MOBI、AZW、AZW3、FB2、CBZ、CBR。依据明确的电子书 MIME，或通用／相应容器类型与扩展名的组合；具体的图片、音视频等类型不能被电子书扩展名推翻。
- PDF、TXT 默认不作为书籍收录。文件或最近一级目录有效策略为 include 时作为书籍加入；目录设置包含全部子目录。Word、表格等其他文档不因此成为书籍。
- 相册、影视、书籍首页按直接父文件夹分组，显示数量、总大小和最多四个封面样本。打开文件夹只展示直接包含的文件，书籍与影视按文件名自然排序。音乐保持现有按专辑名归类。
- 书籍沿用文件预览：EPUB、PDF、TXT 可用现有阅读器，其他格式展示现有预览回退及下载入口。新增 EPUB、MOBI／AZW／AZW3、FB2、CBZ／CBR 自动读取内嵌封面或漫画图片；历史书籍在「编辑元数据 → 内置封面」手动读取。没有封面时显示书籍图标；PDF 首页暂不生成。详见 [书籍封面读取](book-covers.md)。

## 规则与生命周期

文件与目录均有 auto（跟随）、include（收录）、exclude（排除）三种设置。优先级为：文件明确设置 > 最近一级目录明确设置 > 按格式自动收录。目录的 auto 表示移除本级规则；不会覆盖子目录或文件的明确设置。

文件策略保存在 schema v46 的 file_metadata.library_policy；改名、移动、回收站与恢复时沿用。内容覆盖建立新的文件元数据，策略恢复 auto；同内容重复提交保持已有记录。同账号复制沿用文件明确设置，跨账号转存恢复 auto，不传播对方的展示偏好。

目录规则按桶保存在 settings 的 library.folders.<bucket_id>，新增普通目录规则的上限为 200 条（包含全库默认规则；恢复目录导致已有规则超限时仍可调整或移除）。全库默认为 auto；把根目录设为 exclude 可实现仅收录明确指定的文件或目录。目录移动在对象移动事务内同步规则，合并时目的地已有的明确规则优先；有冲突跳过的源文件保留原规则。移入私密空间或回收站的规则隐藏，移回普通空间时恢复；永久删除目录后清理对应规则。

## 网页接口

- GET /api/user/v1/library?view=recent|photos|videos|music|books：键集分页；collection=included|excluded|all，默认 included。recent 不使用收录筛选。
- GET /library/folders?view=photos|videos|books 与 GET /library/albums：接受同一 collection 参数。筛选在 SQL 分页、聚合及选取封面样本之前完成，列表、搜索、数量与封面一致。
- GET /library/policy?path=：读取文件或目录的直接策略、有效策略及继承来源；空路径表示根目录。目录同时返回递归文件数量，包含子目录明确设置的文件，数量仅用于说明影响范围。
- POST /library/policy：paths 为 1–1000 个普通文件／目录路径，policy 为 auto|include|exclude。路径以 / 结尾表示目录，空串表示根目录。完整校验后原子提交，使用网页会话与 CSRF，禁止进入系统区或私密空间。
- GET /library/rules：只返回当前桶的普通目录规则。文件策略仍由文件接口读取。

书籍「未收录」也包含没有指定收录的 PDF、TXT。「全部」显示支持的候选文件和当前收录状态。文件、目录与多选菜单均可设置；媒体卡片可直接排除／加入，各页的收录规则窗口可以设置根目录与目录规则。更新广播 tessera:library-updated，刷新媒体列表、分组及专辑统计。

本功能不使用 AI、不推断歌曲／录音或电影／录屏等内容语义、不调用模型或在线信息来源。收录查询只读取本地元数据，无后台内容扫描。

## 文件操作

照片、影视、书籍卡片，以及音乐专辑、搜索结果和歌单中的曲目，均支持右键菜单；内容与更多菜单一致，包含「编辑元数据」。右键只打开菜单，不启动预览或播放、不改变已有选择。元数据编辑器由媒体库外层持有，列表刷新时仍保留未保存的修改；保存后歌单合并最新标签和封面，不改变曲目顺序或成员。

# 文件级元数据与关联资源

音视频的内容与可编辑元数据分离。编辑字段、歌词、字幕、封面不改原文件、不改变其 ETag，也不触发完整媒体重新上传。普通下载仍返回原始文件。

## 数据与生命周期

- 每个文件有独立的元数据编号，改名、移动、移入或移出私密空间、回收站与恢复时随对象保留。内容覆盖生成新的元数据记录；相同内容的重复提交保留已有编辑。复制、分享转存复制元数据及小资源引用，不读取或重新上传媒体内容。
- 解析得到的初始字段与用户覆盖字段分开保存；用户编辑优先，异步初始化不能覆盖用户修改。字幕删除按内置来源保留标记，避免被重新提取；仍可初始化未编辑的其他语言。编辑使用原内容 ETag 与独立的元数据 revision 做并发检查。
- 歌词、字幕、封面正文均通过现有加密对象存储保存到所属桶的 `.tgdrive/`，计入用户配额。数据库只存字段、资源引用、语言、名称、默认项及状态。替换小资源先保存新对象、提交引用后释放旧对象，失败不丢失旧资源。
- 自动封面保留已有三种规格与内嵌优先／视频无封面时截帧规则。手动封面作为文件级覆盖，不能串改其他同内容文件。
- 删除文件的元数据与资源随回收站保留，永久删除或覆盖时释放；后台初始化、写资源及读取均检查当前对象、桶、版本和授权。私密资源通过源文件授权读取，隐藏对象不能绕过私密解锁或分享访问密码。

## 初始化与播放

- 所有写入入口完成后触发首次初始化：只解析字段（标题、艺人、专辑、年份、作曲、导演、演员、简介、时长等），读取文件头与索引，有解析缓存时不读取；新文件优先处理，刚写入的数据多半还在短期密文缓存里，不必回源。歌词、字幕不在上传时提取。其他文件保留封面管理。状态持久化，重启后可继续，暂时读取错误可重试。升级时已有解析缓存的旧文件直接复制为首次字段，其余由后台补齐。
- 播放与编辑优先使用已保存的歌词、字幕；没有保存时回退到文件内置的：内置歌词只读文件头；内置文字字幕在首次选择时由 FFmpeg 经回环地址按范围读取，一次输入提取全部未保存的文字轨（仅输出受限的小字幕，不生成完整视频临时文件），并保存为元数据，以后不再为字幕读取原视频。用户清空过的歌词、在编辑器里排除或删除过的内置字幕不再回退。图片字幕不伪装成文字字幕。
- 同目录文件只出现在编辑器的手动导入入口。
- 音乐库的专辑归类、搜索、曲目排序与列表显示的歌名、艺人、专辑、时长只读文件级元数据（手动修改 > 首次解析），不再读取按内容的解析缓存。分享页只使用已保存的歌词、字幕，不回退到文件内置数据。在线候选保存为隐藏关联资源，不新增可见的同名歌词或字幕文件。

## 界面

- 音频：信息、歌词、封面；信息包括歌名、专辑、歌手、专辑歌手、发行年份、曲目、流派等。
- 视频：信息、字幕、封面；信息包括标题、创作者、导演、演员、发行年份、题材、简介等。
- 其他文件：只显示封面。
- 字幕支持多轨管理，独立名称、语言、默认项、添加、修改与删除；未保存的内置字幕轨可「提取保存」或「不再使用」。歌词和字幕支持本地上传、同目录导入、粘贴、在线查找。保存只传修改字段和小资源。
- 信息页可「在线查找信息」：复用已启用的封面／歌词来源（网易云、QQ 音乐、酷狗、LRCLIB、iTunes、MusicBrainz、豆瓣、TMDB、Bangumi、TVmaze）的搜索结果中的结构化字段，加上文件自带的标签；逐项勾选后填入编辑框，保存元数据后生效。

本文是实现契约；数据库迁移仅添加到源码，不对用户现有数据目录执行迁移或初始化。

# Tessera 系统检查与优化（2026-10-09）

本轮围绕大数据量列表、文件操作位置、网格布局及预览反馈，检查网页组件、ASGI 路由、会话权限、对象查询和现有回归测试。已实现下面的改进。界面截图来自本轮构建与独立的内存演示服务；后端行为由临时数据回归测试验证。

## 主要发现与处理

| 问题 | 处理 | 影响 |
| --- | --- | --- |
| 用户、密钥、分享、回收站全量读取；部分文件列表通过“加载更多”不断累积 | 统一游标分页：一般每页 50 项，审计日志 30 条；只保留当前页和游标历史 | 控制响应体和页面节点数量 |
| 全部密钥为每条客户端分别读取密钥与授权 | 按本页批量查询关联数据，关联用户名直接返回 | 消除每条客户端额外两次查询 |
| 概览读取全部用户做统计 | SQL 汇总，总量完整，排行榜和空间提醒各最多 8 位 | 避免全量用户传输 |
| 文件公开筛选在已加载页面内过滤 | 改为服务端筛选后分页 | 后续页的公开文件不会被忽略 |
| 侧栏分享数量受旧列表上限影响 | 查询分页接口的完整总数 | 总数不依赖本页数量 |
| 上传、新建文件夹缺少位置选择 | 共用分页目录浏览器，支持面包屑和新建子目录；移动也复用 | 可确认完整目标位置 |
| 上传覆盖提示只看已加载文件 | 按完整目标路径分批检查，每批最多 200 个 | 翻页后仍能提示同名覆盖 |
| 网格图片比例影响卡片尺寸 | 固定缩略图区与信息区，图片在区域内裁切 | 横图、竖图、普通文件尺寸一致 |
| 预览加载缺少明确反馈 | 转圈、加载文案、媒体事件及错误下载入口；关闭文本预览取消读取 | 区分等待、就绪和失败 |
| 文件表格仅有图标，没有类型文字 | 我的文件、全部文件、公开分享、访客公开目录新增类型列；网格显示类型 | 文件类型更容易辨认 |
| 窄屏审计和个人密钥表格撑宽页面 | 表格局部横向滚动，分页留在面板内 | 页面本身不再横向溢出 |

新增管理员统计接口要求管理员会话；目录和同名检查仅访问当前用户的桶。同名检查的 POST 同样要求 CSRF。列表显式传入 limit 才启用新分页，旧数组响应保持兼容，程序接口与 S3 契约不变。

## 界面检查步骤与证据

验证截图随本轮本地交付保存，未收录到仓库。下面记录对应操作、观察结果与验证范围。

1. **列表分页：正常。** 我的文件、用户、全部文件、全部密钥、个人密钥、回收站、公开分享、访客公开目录和审计日志均验证翻页替换内容。用户和密钥使用 75 项，文件使用 125 项，公开分享使用 63 项，回收站使用 70 项。末页禁用下一页，返回上一页恢复对应内容。窄屏表格可局部横向滚动。


2. **位置选择：正常。** 新建文件夹可选文档目录；目录浏览器验证了 62 个子目录的两页切换。再次点击当前位置面包屑不会让确认按钮失效。目录加载失败时提供重试。


3. **上传确认：正常。** 通过文件选择器选取自制测试文件，改选文档目录，显示完整目标位置与同名覆盖提示。未开始真实文件上传，本步骤验证选择和确认界面；上传队列沿用原有流式上传逻辑。


4. **网格及类型：正常。** 使用 80×400 竖图、800×80 横图和文本文件。窄屏卡片均为 206.5×194px（含边框），图片比例不会撑开卡片。网格文字显示类型和大小。


5. **预览反馈：正常。** 延迟文本响应时显示加载动画，响应后显示内容并隐藏加载提示。图片就绪通过 load 事件处理；视频、音频与 PDF 的分支已完成静态检查。


6. **手机端面板操作：正常。** 修复标题说明挤压筛选按钮的问题，带说明的面板在手机端将操作区放到说明下方。分段按钮不收缩、文字保持单行，多个完整控件可换行。核对 320、375、430px 手机宽度及 1280px 桌面布局，审计筛选交互正常。

## 范围与限制

- 没有读取或修改用户的 .local-data，也没有对真实数据库执行迁移或数据操作。没有新增运行时依赖。
- 当前文件名称／大小／修改时间排序仅作用于本页，页面和交互文档已明确提示。需要跨页全局排序时，应在后端定义稳定的复合排序游标。
- 上传同名检查是确认时的提示；检查到实际提交之间仍可能发生其他写入，提交保持原来的同名覆盖语义。
- PDF 的加载就绪以浏览器 iframe load 事件为准，无法据此保证内置 PDF 阅读器已经绘制全部页面。
- 总数统计与关键词搜索仍可能随记录数增长而耗时。后续宜用代表性的真实规模数据测量，再决定索引或统计缓存；本轮不引入数据库迁移。
- 本轮不是完整渗透测试或全站无障碍认证。截图、读屏状态和键盘操作不足以证明全部浏览器、读屏软件及媒体格式兼容。
- 界面使用内存演示响应，未验证真实 Telegram 上传、下载网络链路；已有后端测试覆盖相关底层行为。
- 构建产物已更新。正在运行的后端需重新启动以加载修改后的 Python 代码。

# 资源抓取脚本

给 AI 代理的模块细则（由根目录 AGENTS.md 索引）。userscripts/tessera-grabber.user.js：兼容层、iframe、批次、网盘取链与网盘文件夹。

- `userscripts/tessera-grabber.user.js`：资源抓取用户脚本，兼容 Tampermonkey／Violentmonkey（同步 `GM_*`）与 iOS Userscripts + Safari（只有异步 `GM.*` 和 `GM_xmlhttpRequest`，没有 `GM_cookie`、菜单命令；需要 `@inject-into content`）。所有 GM 调用都经顶部兼容层 `gm`（`gm.get/set` 读写启动时预读的内存缓存、`gm.openTab`、`gm.copy`、`gm.xhr`、`gm.menu`），不要再直接调用 `GM_*`；新增存储键时加进 `STORE_KEYS`。没有菜单命令时（`HAS_MENU` 为假）未启用的网站保留淡化悬浮按钮（`dormantFab`），窄屏面板以贴底的底部抽屉展开（`placePanel` 的 `is-sheet`），资源行只留「更多」与服务器下载，其余操作经 `openActionSheet` 在面板内弹出（同样登记在 `panel.layer`）；资源嗅探在观察器之外定时读取 `performance.getEntriesByType("resource")` 兜底。脚本不再声明 `@noframes`：iframe 里只运行 `frameAgent`（在启动段 `if (!IS_TOP)` 处提前返回，不注册菜单、不读写 GM 存储与设置、不挂界面），收到父窗口的 `frame-scan`（`FRAME_CHANNEL`，顶层启用时每 2 秒发一次，打开面板时带 `dom`）后才嗅探，并把自己与下级框架的资源以 `frame-items` 逐级交给父窗口；顶层 `onFrameItems` 只接受子框架（`fromChild`）的消息并经 `frameItem` 逐字段校验，停用时发 `frame-stop`。框架资源带 `referer`（框架页面地址）与 `frame`，curl 与浏览器读取用 `refererFor(url)` 取它。不要向框架发送设置、密钥或其他数据。（单文件、无构建步骤，界面放在封闭 Shadow DOM 中，一律用 DOM API 创建节点，不得使用 `innerHTML`／`DOMParser`／`eval`：YouTube 启用了 Trusted Types，这些调用会直接抛错导致脚本挂载失败）。只通过访问密钥调用 `/api/v1/downloads/parse`、批量解析 `/api/v1/downloads/parse-batch`（`parseEntries` 把非平台条目每 `PARSE_CHUNK`=20 个合成一个请求、两路并行，X／YouTube 逐个走 `parseEntry`；单项 `error` 只标红该行，`retry` 项用单项接口再解析一次；旧服务器返回 404 时 `parseBatchMissing` 退回逐个解析）、`/api/v1/downloads`、浏览器上传用的 `PUT /api/v1/files`、提交文件名用的 `POST /api/v1/move`、清理临时对象用的 `POST /api/v1/delete` 与目录选择用的 `GET/POST /api/v1/folders`（`KeyApi.folders` 只列一层、排除 `.tgdrive/`），不得依赖网页会话接口；私密空间使用额外的短期授权，见下方「脚本私密解锁」；普通访问密钥接口仍不能访问系统区，不得在第三方页面的 DOM 中收集密码。选择层是面板内的覆盖层（`openPicker`，`panel.layer`），不得替换面板内容；生成的 curl 必须能被 `offline/request.py` 解析（bash 单引号，`'\''` 转义）。批量发送的进度来自 `GET /api/v1/downloads?ids=`（`OfflineDownloads.status_of`，默认只返回密钥所属用户、可读路径内的非私密任务；私密轮询显式携带短期授权与 private_scope）；轮询会频繁刷新的界面（批次横幅、进度行、底部按钮）必须原地更新节点，不能整块替换，否则会吞掉用户的点击；资源列表同样按地址复用行节点（`syncChildren`），按住鼠标期间暂停刷新。已发送记录存在 `GM_getValue("sent")`，只有任务创建成功或浏览器上传收到文件保存确认才写入，失败或停止时移除。浏览器上传优先网页 fetch（图片尝试缓存），跨域读取失败或网页 403 时再尝试一次 GM 请求；保持原始字节，拒绝 HTML／验证页面，单文件最多 64 MiB、一次只处理一个文件，普通目录按密钥授权写入；私密目录解锁后通过 `/api/v1/private/files` 上传，再用对应的 move 提交临时对象，不再转交主站确认。本地下载（`mode: "local"`）与服务器下载（`mode: "server"`）共用 `startBatch` → `renderBatch` 确认页：服务器下载打开时先 `parseEntries` 解析，每个分组替换成一行（`variants` 下拉、`candidate`、可改 `name`），开始后逐行 `createEntry`；确认页骨架按阶段只建一次、列表用 `syncChildren`，解析结果到达时不能重建输入框。普通资源的 GM 请求不要改写 User-Agent（网盘取链例外，见下条）；Cloudflare 验证（`challengeError`）只能由用户在标签页里通过，失败行提供「打开验证」。来源 Cookie 不转发到上传接口，Tessera 密钥不进入来源请求；确认页可编辑每项保存文件名，校验路径、控制字符、保留名、220 字节上限与批次重名；PUT 先写入自己随机临时名，再用 move（conflict=skip）提交到确认名，避免同名覆盖，失败后只清理自己的临时对象。同一条目重试沿用临时名，修改保存名后更新提交目标。已探测资源只在手动「清空」或刷新页面时清除：`collect` 把 DOM 扫描结果经 `remember` 存入 `items`（上限 `MAX_ITEMS`），`checkNavigation` 换页时不删除资源，新增清理路径前先确认用户意图。资源大小：`resourceMeta` 按地址缓存大小与图片尺寸，来源依次是资源计时（`timingSize`，仅图片／文件）、已加载图片的天然尺寸、视口内行的探测（`watchSize` → `pumpProbes`，`PROBE_LIMIT=3`，`requestSize` 先 HEAD 再 `Range: bytes=0-0`，读到响应头即中止）；探测失败或遇验证页面记为未知、不重试，结果经 `syncMeta` 原地更新行副标题（`describe`）。回归检查：`node --test tests/test_grabber.cjs`（`harness({ manager: "async" })` 模拟 Userscripts 环境，关键流程两种环境都要覆盖）。
- 网盘取链内置于抓取脚本的「内置网盘适配」区域，基于 LinkSwift 固定提交，出处、原始快照、函数映射与只读比对工具见 `third_party/linkswift/`。运行时仍是单文件，不加载快照或远程脚本。九个适配器读取网盘当前选择，异步 `cloudSources` 建快照，`parseEntries` 先用 `cloudResolveAll` 按 LinkSwift 的节奏批量取链（`CLOUD_PACE`：夸克／UC 每请求 15 个 fid、百度自盘 50 个 fsid、阿里 3 路并行、其余 15 路并行、百度分享逐个，批间停 `CLOUD_PAUSE` 1 秒；多文件请求失败时逐个重试），`parsePayload` 等待各自的直链，再经 curl 文本交给批量解析与创建接口；网盘里勾选的文件夹见下文「网盘文件夹」；勾选的文件即使之前发送过（`isSent`）也全部进入确认页，标「已发送过」（`resent`）并提示，可移除，不能静默跳过或整批拦下；网盘文件与网页资源的勾选数量都不设上限（页面快照不截断，网页资源列表也不再有 50 项的勾选上限），批次可以并行：`batch` 是面板正在查看的批次，`batches` 是已开始、仍在跟踪的全部批次（`runBatch` 开始时登记，`clearBatch(current)` 移除），运行中的循环用 `batchAlive(current)` 判断是否继续，不要改回 `batch === current`（否则开始新批次会让旧批次停下）；`startBatch` 不再拦截进行中的批次，只清掉已结束的记录并跳过正在其他批次里处理的地址，`poll` 遍历全部批次，主面板每批一条横幅（`bannerFor`，节点按批次复用），本地下载跨批次经 `localTurn` 依次处理。`startBatch` 按 `batchLimit()`（设置项「每批文件数」，存储键沿用 `cloudBatch`，网盘与网页资源共用，默认 `BATCH_DEFAULT`=100，上限 `BATCH_MAX`=500，非法值按默认：一批取链与解析都完成才创建任务，批太大时前面的直链与解析票据（`offline/service.py` 的 `TICKET_TTL`，30 分钟）会过期，不要随意调大上限）自动分批，批大小在开始时记入 `batch.limit`，`nextRound` 沿用它：确认页只放第一批（`batch.entries`），其余存 `batch.deferred`（`round`／`rounds`／`archivedOk`）；`runBatch` 创建完一批后 `nextRound` 把已完成的行收起为 `archivedOk` 计数、取下一批（`autoRound` 行解析后直接 waiting）并 `runBatch(true)`（跳过改名检查；通过 `runBatch(true, current)` 保持各批次独立，本地上传模式不解析），直链与解析票据都会过期，不要改成一次取完全部；私密空间授权有效时同样自动发送下一批，过期后在面板里重新解锁；`dropRounds` 放弃未开始的批次；`batchDone`／`batchSummary` 计入 `deferred` 与 `archivedOk`，轮询 `?ids=` 每次最多 100 个；重试重新取链并保留修改名。`@inject-into content` 下不能假定 `unsafeWindow` 可访问 React／Vue 状态；`cloudReadSelection` 是可独立运行的只读函数，必要时经 `gm.pageScript`（优先 `GM_addElement`，否则 DOM 创建）把白名单文件字段放进临时脚本节点的 DOM 属性，读完立即移除；不得向页面桥接 GM、Tessera 配置／密钥或通用执行能力。阿里自盘支持列表／网格，阿里、移动和迅雷分享页只给转存说明与「打开我的网盘」。百度自盘除文件列表（`.wp-s-core-pan`／`.file-list`／`system-core` 上下文）外的视图（图片分类时间轴、搜索结果等）：旧来源都读不到时，在页面 Vue 2 组件（含 `$parent`）的 `$data`／计算属性／props 与 Vuex `state`（深度 3）、`getters` 里找名字含 select／check、元素都带 `fs_id` 的非空数组，只有找到才算识别（避免把无关数组当成勾选）。百度分享页 2026-11 起为新版 `disk-share-v2`（Vue 3，无 `__vue__`）：旧来源读不到或为空时，`cloudReadSelection` 从 `.JS-list-view-item[data-file-key]` 行的 `.wp-checkbox--checked` 读勾选、按 `locals.file_list` 补齐文件，单文件分享（`SHAREPAGETYPE` 含 single）直接取页面文件；分享参数兼容 `locals.get()`／`yunData`，`sekey` 依次取 `currentSekey`／locals／`BDCLND` Cookie，页面自带 `sign`／`timestamp` 时 `cloudBaidu` 不再请求 `tplconfig`（参考上游 PR #557，见 `third_party/linkswift/UPSTREAM.json` 的 `patches`）。网盘取链请求与 LinkSwift ## 脚本私密解锁

- `private_keys.py` 为所属用户根目录读写密钥提供 `/api/v1/private/*`，必须同时绑定 GM 存储的随机 `private-client`（`X-Tessera-Private-Client`）与内存中的短期 `X-Private-Access`；受限前缀、只读、无所属用户的密钥不能解锁。普通密钥与 S3 接口仍拒绝私密路径。
- 密码只在 Tessera 来源的 `/grabber/index.html` 独立文档中输入，脚本面板内嵌 iframe，禁止第三方父页面获取密码。专用 MessageChannel 传递密钥、安装标识与授权，全局 postMessage 只传不含秘密的 ready/connect，父端校验来源和精确窗口。该入口不初始化网页会话，fetch 使用 `credentials: omit`；只有此 HTML 允许被嵌入，主站仍禁止。网页 CSP 禁止 iframe 时提供独立小窗口；通行密钥已绑定且浏览器、权限策略允许时显示快捷解锁，失败可用密码。
- `KeyPrivateAccess` 只在内存保存每把密钥和脚本安装的内部会话，复用 PrivateSpace 的账号验证、限速、闲置时间与失效规则，内部会话 token/CSRF 不返回客户端。密码不保存，短期授权不写 GM 存储；同一安装换网页后可通过 status 恢复未过期授权。
- 私密目录浏览、新建、上传字节、创建任务及可信的面板交互续期；status 与下载进度轮询不续期。闲置到期清空目录列表、隐藏私密目标路径并取消进行中的本地私密上传，服务器已创建的下载继续；进度页用「解锁并继续」恢复等待发送的条目或重新查询状态。每个写入分片和提交仍校验账号、密钥与授权；move/delete 只允许提交或清理同目录脚本临时对象，不覆盖已有文件。
- 回归：`tests/test_private_key_access.py` 与 `tests/test_grabber.cjs`；浏览器检查跨来源 iframe 的 MessagePort、密码输入、取消返回目录层、超时与窄屏／深色显示。

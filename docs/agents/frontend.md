# 前端结构与界面组件

- 新书籍上传通过 `bookCoverSource` 判断明确电子书／漫画格式，在已有生成票据内调用 `createBookThumbnails`：服务端提取原图，浏览器生成三尺寸。`ThumbnailEditor` 为这些格式显示「内置封面」，不增加在线查找或截图；PDF／TXT 不显示此来源。`useThumbnailPolling` 只为近期书籍查询状态，不触发历史文件提取。详见 [书籍封面读取](../book-covers.md)。

- 媒体库 `MediaItems` 的右键与更多菜单共用 `itemMenu`，照片／影视／书籍卡片及专辑／搜索／歌单曲目都可编辑元数据。右键状态按文件 key 解析最新项，滚动或条目消失时关闭；菜单 portal 到页面根部。`MetadataEditor` 由外层 `MediaLibraryView` 持有，避免查询刷新卸载编辑器。歌单监听 `FILE_UPDATED_EVENT` 合并最新文件字段并保持顺序。
- 元数据字段的恢复操作复用 `Button size="sm" variant="ghost"` 与 `metadata-field-reset`，使用辅助文字色和恢复图标，不再用 `.link-button`；保留原有恢复后待保存的语义。

给 AI 代理的模块细则（由根目录 AGENTS.md 索引）。web/src 的组件、预览引擎、文档站、样式与主题。

- `thumbnails.ts`：网页上传优先从本地文件取内嵌封面，视频没有时按既有时间点截图并过滤空白画面；音频仍只取内嵌封面。预览页的 `videoPreviewThumbnails` 没有内嵌封面时返回 `null`、交还生成权，由后台截图补齐，不能写入 `none` 阻止后续补图。详细约束见 [media.md](media.md)。

  - `ui.tsx`：设计系统基元（按钮、表单、弹窗、菜单、toast、格式化、配置页的 `SetupGuide` 配置指南）。新界面必须复用这里的组件。弹窗里再打开的 `Modal` 经 `ModalDepth` 上下文按嵌套层级排序（`--modal-depth` 提高 z-index，`modalStack` 按层级插入并由 `syncModalInert` 只让最上层可操作）：React 先挂载子组件，同一次渲染里同时打开的内外两层不能按挂载顺序叠放。列表行操作遵循 `DESIGN.md`「列表行操作规范」：一个快捷操作 + ⋯ 菜单，删除、禁用／启用等只放菜单末尾并确认。存储通道的指南步骤（`admin/bots.tsx` 的 `STORAGE_STEPS`）是管理员文档「存储通道」页的精简版，两处同步修改。
  - `shell.tsx`：应用外壳、登录页、首次初始化页。
  - 菜单的二级菜单用 `MenuItem.children`（`ui.tsx` 的 `MenuList` 渲染，单独 portal 到页面根部）。文件页的「新建」菜单与空白处右键共用 `user/files.tsx` 的 `newItems`；可新建的文本类型在 `NEW_FILES` 里加一项即可（`api.createTextFile` 写空文件，打开预览时 `startEditing` 直接进入编辑）。空白处右键靠 `.files-view` 铺满一屏，行上的右键已 `preventDefault`，外层据此区分。
  - `files.tsx`：文件类型、预览入口与分享对话框。`preview-data.ts` 负责流式文本解码与 16 MiB 截断；`preview-text.tsx`、`preview-media.tsx`、`preview-image.tsx` 提供文本／音视频／图片界面（音乐用原生 `Audio` 自绘界面，动画是 `Turntable` 唱机（网易云式大唱片，封面占三分之二；转盘、光照层、轴心不随唱片转动；无封面时标签与背景用 `coverTint` 按文件名选的 `--series-*` 色调）：唱片用 JS 按速度缓动转动、唱针随播放落下／抬起，不接 Web Audio，所以 iOS 锁屏与后台播放不受影响；上一项／下一项、播放模式与列表按钮放在各播放器自己的控制条里）；`preview-*-engine.ts` 用 CodeMirror、markdown-it／DOMPurify、ArtPlayer、pdf.js 实现预览并按需加载；PDF 界面在 `preview-pdf.tsx`（只绘制视口附近的页并释放远处画布，文字层 CSS 取自 pdf.js 的 `.textLayer` 规则，改动时对照 `pdf_viewer.css`），pdf.js 的 Worker、字符映射、标准字体与解码器由 `build-apps.mjs` 复制到 `dist/pdfjs/<版本>/`，不加载外部资源（助手输入框 `composer-engine.ts` 同样单独打包）。同目录 LRC／SRT／VTT 查询沿用用户、管理员和公开文件夹的权限边界。
  - `markdown.tsx`：自带 Markdown 渲染器，直接产出 React 元素，不执行原始 HTML，链接只放行 http(s)/mailto；`highlight.ts`：正则语法高亮（每种语言一组规则，合并成一个正则扫描，规则内不得有捕获分组或后行断言）；`code.tsx`：带行号的代码块与 Markdown 围栏。新增语言只需在 `highlight.ts` 的 `RULES` 与 `ALIASES` 各加一项。
  - `user.tsx`（入口 `UserApp`，含移动对话框与拖放移动；「设置」不在侧栏，只从头像菜单进入，`user/account.tsx` 的 `UserSettingsPage` 分「账号」与「访问密钥」标签页，访问密钥是嵌入的 `KeysView embedded`，地址 `?view=account&tab=keys`，旧的 `?view=keys` 由 `readLocation` 兼容）；`user/folder-stats.tsx` 是目录统计弹窗（`GET /stats` 递归聚合，类型颜色用 `--series-*` 令牌）、`admin.tsx`（入口 `AdminRoute`，含系统设置）、`share.tsx`。
  - 文件助手：`assistant-api.ts`（接口类型与 SSE 订阅 `subscribeRun`）、`user/assistant.tsx`（右侧抽屉；右下角入口是 `user/assistant-launcher.tsx` 的 `AssistantLauncher`（只放助手），⌘/Ctrl+J，入口不在侧栏，见设计 §34；访问模式、浏览器工具执行）、`user/assistant-thread.tsx`（按轮分组的消息流：思考、工具时间线、各类卡片）、`user/assistant-bridge.ts`（文件页向助手暴露当前目录与选择）、`user/assistant-mentions.tsx`（@ 引用候选：由输入框报告 @ 片段，选中后经 `onPick` 插入 `@显示路径`（`mentionLabel`：普通 `/路径`，私密 `私密:/路径`），候选只来自当前目录及其子文件夹（搜索经 `api.searchFiles` 的 `prefix` 限定，范围由 `scopeOf` 统一计算），超出作用域时计算公共上级目录（只算普通引用）；已解锁时在私密空间页面或输入 `@私密:` 列出与搜索私密空间）、`user/assistant-composer.tsx`（输入框宿主，粘贴文件交给附件）、`user/assistant-attachments.tsx`（聊天框附件：上传托盘、消息里的附件与「保存到我的文件」）、`admin/assistant.tsx`（控制台「文件助手」五个标签页（相关页面用分段切换，每段仍有 `/admin/assistant/<分段>` 地址）、模型选择与模型目录、用户策略对话框）。开关控件用 `ui.tsx` 的 `Switch`（表格行内用 `Switch compact`）。
  - 文档站位于 `web/src/docs/`：`docs.tsx`（外壳、`/docs/<页面>` 路由、完整目录、⌘K 搜索）、`docs-ui.tsx`（排版组件）、`docs-content.tsx`（使用指南与接口参考；示例地址取自 `/api/public/v1/config`）、`docs-admin-content.tsx`（部署与管理指南）。全部内容由主应用统一公开展示，无需登录或区分角色。修改接口、限制或 S3 兼容性时必须同步更新对应内容文件。
  - `styles/`（原 `styles.css`，按领域拆成多个文件，构建时拼接）：全部样式与设计令牌；只引用 CSS 变量，深色模式只覆盖令牌（`:root[data-theme="dark"]`，不要再用 `prefers-color-scheme` 媒体查询）。字号用 `--text-*` 阶梯（11/12/13/14/16/20/22/28），圆角用 `--radius-2xs…xl` 与 `--radius-pill`，不写半像素或裸值；令牌块之外不写十六进制或 `rgba()` 颜色，深色媒体画布用 `--on-dark-*`／`--shade-*`／`--dark-surface*`；内外边距与间隙按 4px 网格；文件类型图标统一用中性的 `--glyph-mark`，不按类型配色。表格数值列用 `cell-size`／`cell-count`（右对齐、等宽数字），指标卡片的数字交给 `Stat` 的 `formatCount`。设置类表单有未保存修改时调用 `ui.tsx` 的 `useUnsavedChanges(dirty)`，标签切换等应用内导航先 `await confirmLeave()`（`user.tsx` 的 `navigate` 已统一处理）；`useUnsavedChanges` 是 Hook，必须放在组件的提前返回之前。
  - `theme.ts`：外观偏好（跟随系统／浅色／深色），存 `localStorage` 的 `tessera-theme`；`build-apps.mjs` 生成的 head 脚本 `theme-<hash>.js` 在首帧前应用，二者的存储键与解析规则必须一致。

- 构建与分块（`build-apps.mjs`）：主应用仍用自写打包器，但源码里的 `import("./x")` 会被识别为按需分块——TypeScript 转出的 `Promise.resolve().then(() => require(...))` 改写成 `__lazy(id)`；入口静态依赖进主包，只被一个分块用到的模块进 `chunk-<名称>-<hash>.js`，多个分块共用的放回主包。当前分块：文档站（`docs/docs.tsx`）、系统管理（`admin.tsx`）、文件助手抽屉（`user/assistant.tsx`）。页面用 `lazy.tsx` 的 `lazyComponent`／`Loadable`（加载中显示 `FullPageLoading`，失败给「重新加载」，抽屉用 `fallback={null}` 静默）与 `preload`（空闲时预取）；分块与预览引擎一样保留旧文件，已打开的旧页面仍能加载。主包与分块都经 esbuild `transform` 压缩；构建最后为 dist 下的 js／css／wasm／json／svg／txt 预生成 `.br` 与 `.gz`（文件名带哈希或在版本目录里的只压一次），`static.py` 按 `Accept-Encoding` 返回并带 `Vary`，`index.html` 由服务端改写、不预压缩（`tests/test_auth.py`）。轻量入口模块：`admin-modules.ts`（菜单清单）、`user/assistant-hooks.ts`（助手配置与 ⌘J），不要让外壳再静态导入分块里的重模块。
- 样式在 `web/src/styles/`：`00-tokens.css` 是全部令牌（含 `--z-*` 层级、`--leading-*` 行高、`--shadow-dark-*`），其余按领域编号；新页面的样式加新文件或放进对应领域文件，编号决定层叠顺序。断点只用 480／640／760／860／960／1100（高度 640／720），页面级层级只用 `--z-*`。
- 命令面板 `user/command-palette.tsx`（⌘K，挂在 `PreviewHost` 内）：命令来自 `user.tsx` 的侧栏分组、收藏与常用操作，文件查找经 `api.searchFiles`（200 ms 防抖，8 项）。提示组件新增 `toast.status(名称, 文案)`：同名提示原地更新，用于连续调速、调整歌词时间。
- 系统管理的文件助手页拆在 `admin/assistant/`（每个标签一个文件，`shared.tsx` 放共用常量与格式化），`admin/assistant.tsx` 只负责分发并转出 `AssistantPolicyDialog`／`price`／`tokens`。
- 媒体库 `user/library.tsx`：「最近」与「相册」（只含图片）「影视」（视频）「音乐」（音频）「书籍」（电子书）读 `GET /api/user/v1/library?view=recent|photos|videos|music|books`（`UserApi.library`，键集分页，只含普通文件；`q` 匹配授权前缀下的相对路径，音乐另匹配 `file_metadata` 的歌名、艺人、专辑；`folder` 只列该文件夹直接包含的文件，照片按拍摄时间、其余按路径，空值为根目录）。相册、影视与书籍首页按所在文件夹分组：`GET /library/folders`（`UserApi.library_folders`，只接受 photos／videos／books，`rtrim(key, replace(key,'/',''))` 取父目录、窗口函数给数量／大小／最近时间与 4 个样本，最多 `LIBRARY_FOLDER_LIMIT` 个文件夹，按最近时间倒序），打开文件夹的地址是 `?view=photos|videos|books&folder=<路径>`。音乐按专辑：`GET /library/albums`（`UserApi.library_albums`，`_ALBUM_SQL` 只按去掉首尾空白的专辑名归类、不区分艺人，没有专辑或没有标签记录的歌曲归为空串「无专辑」并排在最后；样本按 `_TRACK_SQL` 曲目号排序，第一首有封面的作专辑封面），`library?view=music&album=` 列一张专辑，地址 `?view=music&album=<专辑名>`。`location.prefix` 带前导 `/` 区分「无专辑／根目录」与未打开。搜索结果按文件夹（音乐按专辑）分段。影视／书籍文件夹与专辑打开时读完（上限 5000）并按曲目号／文件名自然排序；曲目行左侧显示列表内序号（`index + 1`，不显示标签里的原曲目号，合并或只收录部分曲目时会跳号）与每首自己的封面小图；预览用 `anyFolder` 让播放列表跨文件夹；打开专辑时为最多 60 首没有标签记录的歌曲补读 `/media/info`（补读后下次进入才会归到对应专辑）。样式类名用 `media-folder*`（`.folder-card`／`.folder-cover` 已被文件网格占用）。缺封面的轮询统一用 `user/thumbnail-polling.ts` 的 `useThumbnailPolling`（文件页与媒体库共用）。回归 `tests/test_library.py`。星标视图与音乐歌单见 [telegram-stars-playlists.md](telegram-stars-playlists.md)。

- 脚本安全解锁页 `grabber-private.tsx` 是独立入口，`node build-apps.mjs` 默认同时构建 user 与 private，后者输出 `dist/grabber/index.html`；它不加载主站会话 Provider，不读 Cookie，以专用 MessagePort 接收当前脚本的密钥与安装标识，密码不离开 Tessera 来源。仅该 HTML 的响应允许跨站嵌入，主站保持 frame-ancestors none。表单复用 ui 基元及现有通行密钥验证，样式在 `18-grabber-private.css`，窄屏输入字号至少 16px。

- 元数据编辑窗口为 `user/metadata-editor.tsx`（样式 `59-audio-editor.css`），由文件菜单与 PreviewHost 打开，私密锁定时卸载。复用 Modal／Field／Segmented／图片选择器，按类型显示信息、歌词／字幕、封面；未保存修改用 useUnsavedChanges，关闭时确认。保存会轮询 `media/edit/jobs`，取消后检查是否已提交；成功后更新播放器、目录、专辑与缓存。在线歌词弹窗支持直接写入音频，以及给编辑窗口挑选歌词；无 FFmpeg 或不支持的格式保留同目录 LRC 保存。

- 元数据编辑器按音频／视频／其他文件显示相应页；字幕提供轨道选择、名称、语言、默认项与删除，窄屏单列。保存只传字段与资源增量，全部封面使用独立保存流程。 详见 [文件级元数据](../media-metadata.md)。
- 深色媒体表面的模糊铺底（音乐播放器 `.audio-backdrop`、播放列表与最小化小窗的 `::before`）：外扩距离必须大于模糊扩散（约 3σ），否则边缘混入透明、透出深色底，形成一圈「黑边」。有封面铺底的播放列表面板不用实体边框（`overflow` 只裁到内边距边缘，边框区域只剩底色，会成为暗线），改用 `::after` 浅色内描边。唱片投影须落在 `.audio-body` 底部留白内，否则被 `overflow: clip` 截成硬边。
- 音频控制条：播放模式、歌词、播放列表按钮在宽播放器上带短文字（`MediaButton` 的 `text`，容器宽度 ≤600px 时只留图标），开启状态只用颜色区分（开启纯白加粗、关闭半透明灰），不加底色，也不用图标下的小圆点；宽窗口打开播放列表时 `.audio-body` 右侧让出抽屉宽度、唱片缩小，不遮挡歌名。

- 骨架屏：`ui.tsx` 的 `SkeletonCards`／`SkeletonTracks` 与 `SkeletonRows` 共用 `.skeleton` 闪光（`02-layout.css`，减少动态效果时停止）。媒体库 `LibraryState` 的 `skeleton` 按视图传入同形骨架（`itemsSkeleton`／`foldersSkeleton`）。`FileThumbnail` 加载中（含等待重试，`useImageRetry` 的 `gaveUp` 才是放弃）铺 `.thumbnail-skeleton`，`FileVisual` 用 `is-loading` 闪光；加载状态按地址记录，不在 effect 里重置。歌单分享页 `/m/` 页头用第一张封面的模糊铺底与歌单名色调，首屏是 `PlaylistShareSkeleton`。书籍网格最小列宽 116px（窄屏 3 列），书籍文件夹 136px。
- 媒体库收录设置：`user/library-policy.tsx` 复用 Modal、单选与 FolderPicker，文件／目录／多选入口共用。`library.tsx` 的上下文共享 included／excluded／all，查询、目录样本、专辑统计与全部播放采用同一范围；保存后广播 `LIBRARY_UPDATED_EVENT`。书籍使用 3:4 卡片，PDF／TXT 默认在未收录中，可按文件或目录加入。只改展示偏好；规则契约见 [媒体库与收录管理](../media-library.md)。
